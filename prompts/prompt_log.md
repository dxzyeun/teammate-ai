# 프롬프트 기록

## 1 - 프로젝트 주제 및 개발 환경 선정

파이썬을 사용해 AI 기반 조별과제 관리 웹앱을 만들고 싶어.

기능:

* 팀원 관리
* 작업 등록 및 완료 처리
* 진행률 확인
* 기여도 시각화
* AI 활용 기능

또한 파이썬으로 웹 UI를 구현하기 쉬운 프레임워크를 추천해줘.

→ Streamlit 추천

---

## 2 - 프로젝트 구조 설계

AI 조별과제 매니저를 만들고 싶어.

팀원, 작업(Task), 프로젝트(Project)를 관리할 수 있도록 프로그램 구조를 설계해줘.

필요 기능:

* 팀원 추가
* 작업 추가
* 작업 완료 처리
* 프로젝트 진행률 계산
* 팀원별 담당 작업 관리

→ models.py 설계

---

## 3 - 자연어 입력 기능 기획

사용자가 작업 내용을 문장으로 입력하면 AI가 내용을 분석해서 자동으로 작업 목록에 등록하는 기능을 넣고 싶어.

예를 들어:

"이다은이 자료조사 끝냈고 윤재웅이 발표 준비 중"

과 같은 문장을 입력하면

담당자, 작업명, 완료 여부 등을 자동으로 추출해서 등록할 수 있는 방식을 제안해줘.

→ parse_tasks_from_text 기능 설계

---

## 4 - 작업 관리 화면 구현

Streamlit을 이용해 작업 등록, 담당자 지정, 완료 체크 기능이 있는 작업 관리 화면을 만들어줘.

→ sections.py 구현

---

## 5 - 프로젝트 대시보드 구현

프로젝트 진행 상황을 한눈에 확인할 수 있는 대시보드를 만들어줘.

표시 항목:

* 진행률
* 완료 작업 수
* 전체 작업 수

→ dashboard 기능 구현

---

## 6 - 팀원별 기여도 시각화

팀원별 담당 작업 수를 기준으로 기여도를 시각화하는 그래프를 구현해줘.

→ charts.py 구현

---

## 7 - AI 프로젝트 조언 기능

현재 프로젝트 상태와 마감까지 남은 기간을 바탕으로 우선순위와 역할 분배를 제안하는 AI 조언 기능을 추가해줘.

→ advice.py 구현
